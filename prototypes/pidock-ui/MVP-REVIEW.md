## 信息架构与交互

- 项目 → 任务 → 会话三层；任务工作区不成为额外顶层。
- 项目总览：任务筛选、目录来源、项目新建/编辑、来源添加/编辑/移除引用。
- 新建任务：普通/定时、多个仓库与普通目录；每个 Git 仓库选择已有目录或独立 worktree，基准分支与路径预览。普通目录明确共享原文件。准备失败有恢复入口，准备未完成时不能开始 Agent 执行。
- 任务页：对话、最多四个可见会话标签、新建/搜索/重命名/归档/恢复/删除会话；独立草稿、权限和模型。目录、分支和共享边界放在按需打开的任务信息栏。
- 对话：模拟回复、停止、单次操作审阅与拒绝、失败保留输入、技能选择、来源路径加入草稿；消息中可展开工具记录，没有终端输入。历史消息保留当轮模型，不因切换当前模型而改写。
- 设置：Provider/模型、MCP、Skills 的内存增删改/启停；Provider 模型出现在会话选择器；MCP 显示状态和模拟失败；Skills 显示来源并通过 `$` 加入下一条消息。认证字段只示意，不接收真实凭据。
- 定时任务：提示词、周期/一次性、时间/时区、Provider/模型、权限、启停、立即运行、记录与可续聊独立会话。新规则默认暂停；任务忙碌（含待确认）时跳过，Provider 或目录失效时明确失败，不替换目标。
- 生命周期：任务归档暂停规则；恢复不自动执行。删除会话不删除任务或目录；定时记录保留会话已删除状态。任务清理单独审阅，共享原文件始终保留，独立 worktree 的未交付代码采用先保留副本的示意流程。
- 导航：搜索项目/任务，窄窗口折叠侧栏。1200px 以下任务信息改为浮层，800px 以下使用可展开导航；720×560 留出对话和输入区域。

首版延后项没有进入新导航：服务编排、环境模板、端口、协议绑定、浏览器、独立文件/差异工作台、复杂用量报表、Packages/Extensions 安装市场、远程与移动端。工具记录的文件/命令信息属于对话记录，不是独立工具工作台。

## 建议评审路径

1. 比较 A/B 的导航与对话面积；打开/关闭「任务信息」。
2. 新建任务，混选仓库和普通目录，切换目录方式；勾选模拟准备失败后恢复。
3. 分别在两个会话写草稿再切换；新建多个会话，查看全部会话、归档/恢复与删除范围。
4. 发送「执行测试」查看审批；发送「失败」查看错误与草稿恢复。停止只结束当前模拟轮次。
5. 设置中添加 Provider 和模型，回任务明确选择；输入 `$` 选择技能，审阅其来源；切换 MCP 状态或编辑后模拟连接失败。
6. 定时任务「立即运行」，从记录打开新会话并继续聊；该任务会话等待审批时再次运行应记录跳过。
7. 归档任务，在已归档页恢复；确认定时规则仍暂停，清理与会话删除分别审阅。

## 原型边界

所有数据在页面内存中，刷新重置。无 Host、磁盘、Git、模型 API、真实凭据、MCP 子进程、资源回收或系统调度。worktree 的 fetch、分支准备、代码保留、清理和错误恢复只用于评审信息与状态，不代表真实执行通过。定时「立即运行」同步生成示例报告，没有实际流式模型响应或自动时钟触发；不虚构下次执行计算。消息时间、用量和报告包含演示数据。

原型不构成生产组件，不迁移当前多个历史覆盖层。用户确认设计后另行拆分并重写正式 renderer，按 #135 核查生产接线与平台验收。当前没有提交/推送本轮原型，没有更新任何 GitHub 验收。

## 本轮验证

- JavaScript 语法检查与文件空白检查通过；未运行生产测试。
- 浏览器中创建 Git worktree + 普通目录混合任务，检查路径示意、独立/共享标签、失败恢复；工作副本路径与分支带创建时的唯一后缀。
- 两会话分别输入草稿并切回核对；新建至第五个会话，当前会话保持可见且可见标签不超过四个；会话归档显示历史与恢复入口。
- 演示命令审批与拒绝；同任务待确认时立即执行定时任务，记录跳过；拒绝后再次运行创建独立会话，可从记录打开。
- 删除一次定时会话，原任务和其他会话仍在，执行记录标记会话已删除。
- 添加 Provider 模型后在会话选择；切换当前模型不改写历史消息模型；输入 `$` 选择带来源的 Skill；MCP 状态切换可用。
- 窄窗口创建定时任务并保存，默认暂停；任务归档确认后进入归档页。
- 1440×900 两种布局均无页面横向溢出；720×560 导航、任务信息浮层、设置和定时页可访问，输入区保持可见。修复了 B 版窄窗口折叠图标栏后全局管理入口缺失的问题。
