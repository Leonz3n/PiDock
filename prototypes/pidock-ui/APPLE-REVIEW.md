## 功能覆盖

「内存交互」表示能体验页面内状态变化；「界面示意」表示只可评审信息与表单。两者都不代表生产功能已实现。

| 领域 | 本版入口与交互 | 边界 |
| --- | --- | --- |
| 项目 | 选择器、总览、新建、编辑、仓库与普通目录、环境管理 | 复用既有内存交互；未连接本机注册表 |
| 任务 | 普通 / 定时、多个仓库、各自远程基线、根目录与路径预览、追加、归档 / 恢复 | 不获取远程代码，不创建 worktree / 链接 |
| 会话 | 多会话、搜索、重命名、归档、恢复、独立草稿与权限、新会话空状态、草稿与共享范围总览 | 不持久化、不创建 Agent 进程；实现与审查有不同示例历史 |
| 输入 | 附件 / 图片、@ / $ / /、来源引用、权限、Provider / 模型、推理、上下文与用量 | 模型调用和用量是示例；不是实际 API 结果 |

| 执行 | 空闲、运行、停止、待确认、拒绝、失败、过期、关注列表 | 复用原型演示状态，不发送真实外部消息 |
| 环境 | KEY/VALUE、任务覆盖 / 共享模板 / 本机私有配置、版本审阅、生效来源 | 不读取真实环境、不保存凭据或共享配置 |
| 服务 | 按服务启停、本地 / 远程、端口与依赖、日志筛选 | 只修改模拟状态；导入与配方仍含表单示意 |
| 浏览器 | 页面标签、新建 / 关闭、接管 / 交还、点选问题、说明、加入当前会话草稿、证据卡 | HTML 示例页面；标记只覆盖两个示意字段，没有真实 DOM、截图、区域框选或网络取证 |

| 交付 | 逐仓库提交 / 推送 / 合并确认与独立结果 | 不运行 Git；真实暂存文件选择、冲突与失败恢复未展开 |

## 已恢复的产品约束

- 中性灰白与蓝色强调，自有界面不使用绿色。
- π 标记沿用居中的 SVG 图形。
- 新任务工具区默认关闭，只呈现对话；按需打开运行、浏览器、文件、日志、命令记录，可逐个关闭或收起。
- #95 已撤销内置终端；用户本轮再次明确选择「查看 Agent 命令记录，不提供内置终端」。本版移除桌面工具、普通目录任务页及远程权限中的终端入口。旧原型文件保持历史内容，不是本版产品范围。
- Git 文件为独立工作副本；普通目录明确标为共享原文件，且不显示 Git 差异。文件内容始终只读，编辑器入口展示所选文件的任务路径。
- 代码引用携带工作区、文件路径、当前版本示意、行号与代码快照；先加入当前会话草稿，发送后仍可展开引用。命令引用也保留输出快照。
- 新会话重命名后仍保持自身消息和空状态，不按会话名称判断历史内容。
- 浏览器切换、新建、关闭或刷新页面后清除当前验证状态，原有引用保留原快照身份。
- 模型位于输入区右侧，附件与权限位于左侧；会话上下文与累计用量分别显示。
- 1440px 宽视图使用并排工具区，1100px 及以下使用抽屉；760px 及以下导航改为可展开侧栏，保留项目与任务入口。
- 720×560 时压缩标题与状态栏，为消息区保留高度。评审工具栏不覆盖输入框。

## 本轮验证

- 浏览器检查项目、环境、用量、定时任务、能力、远程和 Provider 页面入口，未发现脚本错误，各页未出现终端入口。
- 模拟创建多仓任务，核对名称、环境、逐仓库远程基线和根目录；检查多会话与新会话空状态。
- 页面点选问题、填写说明并加入草稿，核对任务 / 会话归属、页面 ID、URL 与快照版本。
- 检查权限浮层和 Provider 表单。
- 检查功能地图，模拟单个仓库提交后其余仓库仍显示未提交。
- 检查 720×560 与 1440×900；页面无横向溢出。窄视图保留导航，工具以抽屉打开；宽视图并排。
- 对新增 JavaScript 执行语法检查。未执行生产测试或真实服务验收。

### 任务工作台细化验证

- 文件路径搜索仅留下匹配项；打开多个文件后标签保留，切换仓库后不会把其他仓库的文件标为当前文件。
- 源码 / 差异切换；选择第 6–7 行，引用确认框显示正确路径、范围和两行示例代码。
- 代码引用与说明加入草稿，新会话为空；切回原会话草稿和引用仍在。发送后消息中仍可查看代码与命令引用。
- 命令记录的全任务筛选展示审查会话记录；失败记录展开显示工作目录、退出码与标准错误，引用不会执行命令。
- 检查 720×560 文件抽屉无页面横向溢出，1440×900 文件区并排显示；宽屏下引用与外部编辑器操作位于固定底部区域，代码独立滚动。

建议按此顺序评审：文件 → `src/detail.ts` → 工作区差异 → 选择 6–7 行 → 引用所选代码 → 加入草稿 → 新建会话 / 切回；再打开命令记录，切换记录范围并引用失败输出。任务浏览器继续提供页面标签、接管 / 交还与示例字段标记。

仍需用户审阅：最常用工作流是否顺手、管理入口的分组、信息密度与工具抽屉尺寸，以及尚未展开的真实交付 / 浏览器区域标记等交互。这里不把「页面存在」当作「全部需求已满足」。
