# Stitch 输出评审清单

本清单用于检查设计稿，不用于勾选 GitHub 功能验收。

## 产品结构

- [ ] 三层管理清楚，没有新增顶层 Workspace；项目不等同于仓库，会话不等同于任务。
- [ ] 已有目录与独立 worktree 都可选择；Git/普通目录可混选，纯普通目录可创建任务。
- [ ] 每来源共享/独立、实际路径与准备状态明确，混合任务没有全隔离承诺。
- [ ] worktree 展示基线/目标路径/分支，fetch 失败不回退缓存冒充成功。
- [ ] 未归属任务不按名称/目录自动归属；身份和重命名分开。
- [ ] 只有首版入口，未带回终端、浏览器、服务、环境、Diff 工作台、远程或复杂报表。

## 会话与执行

- [ ] 当前会话标签在溢出时仍可见；全部会话支持搜索与已归档分组。
- [ ] 草稿、模型和权限归属会话；模型 profile 能区分，历史模型不会随当前选择变化。
- [ ] 空态、流式执行、停止中、停止、失败、待确认/拒绝/过期都有明确表达。
- [ ] 审批能审阅具体操作/载荷/目标/影响，批准只作用于本次；只读模式不暗示可任意写入。
- [ ] 同任务忙碌提示不阻止编辑草稿，也不误加跨任务全局锁。
- [ ] 会话归档/恢复/删除和任务归档/清理分别表达；在途删除先停止与回收。
- [ ] 删除确认写明范围，任务和原文件保留，定时记录保留已删除状态。
- [ ] 已完成步骤和副作用不自动重放，失败保留输入，未知状态不显示为成功。

## 定时和配置

- [ ] 时间/周期/时区、提示词、Provider/模型、权限、保存/启用/立即运行分开。
- [ ] 每次触发新会话，沿用同一任务工作区；历史可打开原会话继续聊。
- [ ] 同任务执行/审批未结束时跳过，有原因；配置失效明确失败，不替换模型。
- [ ] 关窗后台运行与明确退出/休眠的区别明确；不补跑、不唤醒。
- [ ] 模型服务有凭据状态与错误，MCP 有连接状态，Skills 有本地来源与加载状态。
- [ ] 配置到会话使用有闭环；保存配置不等于已连接/已验证。
- [ ] 原型未覆盖的凭据、MCP 调用、流式结果与真实错误设计状态有补稿，未用截图假结果冒充验收。

## 文件与清理

- [ ] 任务归档暂停规则，恢复不自动运行/启用。
- [ ] 共享原仓库、已有工作目录、普通目录清理时始终保留。
- [ ] 独立 worktree 未提交/未交付改动先保护，保留失败不继续删除。
- [ ] 清理清单、逐项结果与部分失败恢复明确。

## 视觉和可用性

- [ ] A 方案以灰白/冷灰/单蓝为主，不混用 Quiet Ledger 暖纸色候选。
- [ ] 无绿色、渐变、玻璃感、大阴影、营销插画或 emoji 图标。
- [ ] π 统一且居中；图标风格与笔画一致。
- [ ] 正文与必要元信息可读，不复刻初稿极小低对比度字。
- [ ] 信息分级清楚，默认对话优先，详情按需打开；没有过多 KPI 卡。
- [ ] 1440×900 和 720×560 画板均可用；小窗口全局入口完整、输入与关闭按钮可达。
- [ ] 长路径/长中文标题不横向溢出，重要事实可明确展开。
- [ ] 键盘焦点、选中、禁用、悬停和错误可区分；状态不只靠颜色。
- [ ] 已移除评审栏、模拟失败开关、调试 ID 等原型控件。

## 返回材料

- [ ] 画板按 Sxx / 页面 / 状态 / 尺寸命名，缺少的状态明确列出。
- [ ] 共用组件和主要状态有统一规格。
- [ ] 附相较初稿的差异说明与仍需产品决策的问题。
