# 05 — 多服务联动与运行状态

**What to build:** 用户为任务选择本地服务和远程依赖，一次启动所需组合；服务自动使用当前任务的地址，两个任务可以同时运行。

**Blocked by:** 03 — 多仓库任务与并行隔离；04 — 图形化环境配置与单服务运行。

**Status:** ready-for-agent

**Parent:** [首版规格](../spec.md)。

- [ ] 一个仓库可以选择多个运行单元；任务视图显示服务、本地/远程位置和实际依赖去向。
- [ ] 先确定端口并解析变量绑定，再启动服务；同一个变量的完整 URL 覆盖规则经过实际配置读取点核对。
- [ ] 两个任务的同名服务使用不同本地端口、日志和可变输出；实际请求只到达所属任务实例。
- [ ] 区分调用依赖与启动前置条件，支持双向调用服务作为一组先监听，再验证联通。
- [ ] 端口被外部占用、启动失败或依赖不可达时显示可定位的失败；重分配地址后更新所有受影响消费者。
- [ ] 运行记录关联代码状态、配置版本、端口、进程身份与日志；未提交代码和旧构建可区分。
- [ ] 界面显示共享外部资源、实例标识和已知配置限制；不会把固定异步队列或 DTM 回调自动标记为隔离成功。
- [ ] 停止一个服务或任务只处理已登记的所属进程树，不影响另一任务或外部服务。

**验证方式：** 两组调用链同时运行并检查请求去向，覆盖双向依赖、端口竞争、启动失败及部分重启；真实仓库在运行前显示依赖缺口。
