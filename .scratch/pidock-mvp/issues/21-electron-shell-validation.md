# 21 — Electron 桌面壳可见浏览器验证（01 回退路线）

**What to build:** 工单 01 已用真实运行证据否决 Electrobun 2.0.1，按既定规则回退 Electron + Bun Host。本工单用**同一组验收场景**在 Electron 上重新验证可见任务页面、调试证据、按任务持久分区、弹窗与视图生命周期，为 02 冻结桌面集成方式。

**Blocked by:** None — 01 已完成并提供回退结论与受影响设计；本工单是 02 的新前置。

**Status:** ready-for-agent

**执行状态：** 未开始。所有验收项待验证。

**Parent:** [首版规格](../spec.md)。结论与失败证据见 [可见页面控制与桌面壳验证](../../../docs/browser-automation-validation.md) 与 [运行时调研](../../../docs/desktop-runtime-research.md)。

- [ ] 主进程运行 Electron 内置 Node，版本固定并记录；Bun Host 作为独立进程承载 pi 运行时、受管执行与调度，记录 Electron、Bun、pi 版本与两者通信方式。
- [ ] 自有界面与任务页面使用不同的 `BrowserWindow`／`WebContentsView`，分属不同信任范围；任务页面与自有界面在同一窗口内同时可见，任务页面不可获得自有界面的本机能力桥接。
- [ ] 自动化操作用户看见的同一页面（`WebContentsView.webContents`），按角色/标签填写控件、等待异步变化；不得用隐藏 `BrowserWindow`、离屏渲染或另一个视图的成功代替。
- [ ] 持久化 `session.fromPartition('persist:…')` 按任务分配，页面句柄按视图分配并绑定任务；同任务的两个标签页与登录弹窗复用任务分区，验证 Cookie／同源 localStorage 共享及弹窗登录回到原页。两个任务同站点使用不同账号或标记，重启后互不覆盖；重开标签不丢登录；关闭视图不删除分区；关闭一个任务不影响另一个。不要求页面级 sessionStorage 跨标签共享。
- [ ] 关键生命周期分别实测并记录：单视图关闭与重开、标签切换、关闭一个任务不影响其余任务、应用重启后分区与登录恢复。
- [ ] 通过 `webContents.debugger`（或受控 CDP 接入）获得按需证据：语义定位与可操作性等待、截图、相关控制台错误与失败请求。输出有界，避免每步转储全部内容。**不能假设 Electron 提供完整的自动化证据 API**，只有实测通过才算成立。
- [ ] 记录 `debugger` 附着／分离行为：打开或关闭 DevTools、关闭 `webContents` 时是否触发 detach，以及控制句柄失效与重新绑定的实际写法。
- [ ] 人工接管暂停后续自动化操作，恢复时重新读取页面状态；页面关闭、弹窗、iframe、下载及开发者工具开关有明确失效／恢复行为，并分别记录是否通过。
- [ ] 记录 Electron 应用的安装包体积与启动时间实测，以及调试端口／接入点的监听面与访问边界；说明是否需要开放本机 TCP 监听。
- [ ] macOS/Windows 分别记录实测结果与待测项；没有可用 Windows 环境时保留明确的平台验证关卡，不能声称跨平台通过。
- [ ] 记录 macOS arm64 DMG 与 Windows x64 单一 EXE 的候选产出、签名和公证路径（Electron 打包工具链），并确认 Bun Host 单文件二进制随包分发且一同签名。实际发布验收归 15。参考[运行时调研](../../../docs/desktop-runtime-research.md)。

**决策关卡：** 若 Electron 也无法在可接受代价内满足视图生命周期、按任务持久化隔离与调试证据，则不得静默改用其他桌面壳，必须把失败证据与候选方案交回用户确认。

**验证方式：** 端到端驱动两个可见任务页面，断言实际 DOM 变化、独立存储、单视图关闭／重开、错误与截图证据，并记录 Electron 与 Bun Host 的实际组合与版本。技术失败先修订方案，不直接进入产品集成。

**执行结果：** 待填写。工单回写时记录实际完成项、验证平台、未通过／未测项、提交与证据指针；只使用仓库既有的五种 triage 状态。
