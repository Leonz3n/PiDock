# 11 — 多 Provider 与会话上下文状态

**What to build:** 用户在桌面端管理多个 Provider 配置，在同一对话中切换 Provider 和模型，并看到准确标识来源和可靠程度的上下文状态。

**Blocked by:** 02 — 单仓库任务与 pi 会话。

**Status:** ready-for-agent

**Parent:** [首版规格](../spec.md)。

**Context:** [pi 接口与数据边界](../../../docs/pi-provider-usage.md)。

**UI 审阅：** 2026-09-20 用户确认添加和编辑 Provider，以及对话模型/推理/上下文浮层与超限禁止切换规则，见 [审阅记录](../../../docs/ui-prototype-review.md)。界面确认不表示真实 Provider 接入已验证。

- [ ] 添加和编辑均提供「同步模型列表」；使用当前 Provider 连接获取候选，仅更新候选，不覆盖或自动增删已配置模型。覆盖成功、空列表、失败、不支持发现及连接改变后重新同步；不从模型 ID 列表推断模型能力。
- [ ] 模型 ID 可直接输入，也可在同步后下拉选择、输入筛选及键盘选择；新增行共用当前 Provider 候选，允许列表外的手填 ID，拒绝同一 Provider 内重复 ID。
- [ ] 显示名称默认填入并跟随模型 ID；手动修改后保留，清空后恢复跟随。保存和再次编辑保留名称及跟随状态，同步不覆盖自定义名称。

- [ ] 可展开模型设置同时支持显示名称、上下文长度、最大输出 Tokens 与图片输入能力；保存/编辑回显、模型选择展示及图片附件兼容性检查使用对应模型的能力，不因协议类型直接假定支持图片。
- [ ] 按已确认的配置界面支持跟随模型目录、不支持推理及自定义档位子集、默认值与高级映射；读取 pi 的实际可用档位并按会话保存偏好。对话使用就近浮层，标出当前选择与模型默认，提供模型设置入口；验证跳级档位、不可关闭、固定档位及旧偏好失效，禁止把所有模型当作支持同一套档位。高级参数映射按所选协议实际验证。
- [ ] 模型列表每行支持上下文窗口 Tokens 的正整数输入、保存和回显，区分模型目录值/默认值/手工值以及最大输出长度；接入 pi `contextWindow`，模型切换后占比与自动压缩使用对应值，当前调用不被配置编辑中途影响。

- [ ] 每个 Provider 支持多个模型的图形化维护，保存及编辑回显完整列表；对话按 Provider 分组选模型，同 Provider 内可切换，逐会话保留 Provider/模型组合。删除已被引用的模型后明确提示不可用，不改写历史或悄悄选用其他模型。
- [ ] 新增和编辑 Provider 提供 Anthropic Messages、OpenAI Responses、OpenAI Chat Completions 三种协议，保存并回显所选值，在列表中标识；逐协议验证消息、流式响应、工具调用及 usage 接入，不通过供应商名或地址猜测协议。
- [ ] 图形化创建、编辑、停用多套 Provider 配置，支持服务地址、协议、模型信息与私有认证引用；同供应商不同配置可并存。
- [ ] 可查看可用模型与认证状态；无效配置给出可定位结果，凭据不进入共享项目模板、对话或普通日志。
- [ ] 对话内模型选择使用输入框旁的浮层，按 Provider 分组，支持 Provider/模型 ID/显示名称搜索、方向键及 Enter 选择、Esc 和点击外部关闭；展示容量、图片能力和当前选择，提供管理入口。切换保留历史与未发送草稿，记录切换事件；历史响应保留实际归属，其他会话与默认配置不被隐式修改。
- [ ] 忙碌回合、工具和压缩期间，切换等待当前执行结束或用户先停止；不能中途改写当前调用与用量归属。
- [ ] 当前上下文超过目标模型上限时置灰并显示占用/上限，真正执行切换前再次校验；对话、Provider 页、命令及其他入口一致拒绝，原模型、历史与草稿不变，不自动压缩或截断后切换。先在当前模型下压缩且占用已更新，或新会话容量足够时，才允许重新选择。
- [ ] 超限使用未格式化 Tokens 数值，覆盖严格大于、等于和小于边界；窗口未知、占用待更新时不当作零而放行。内容能力不兼容仍需单独处理，不静默丢弃历史。
- [ ] 对话展示当前 Provider、模型、可用思考级别、上下文 Tokens/上限/占比，以及生成、工具、压缩、重试等状态。
- [ ] 输入框下方显示占用/窗口/百分比及估算标记；上下文详情使用就近浮层，展示模型归属、会话累计消耗和压缩入口，压缩后累计消耗保留。
- [ ] 上下文估算或待更新明确标识，压缩后不继续展示失效精确值；窗口和预估剩余量随当前模型变化。
- [ ] 配置改名/停用和应用重启后，历史响应仍能识别原 Provider，恢复会话时报告配置不可用而非静默选择另一账户。

**验证方式：** 使用两套 Provider 配置在同一会话连续回答，验证历史和其他会话不变；覆盖忙碌切换、无认证、窗口缩小和压缩后未知用量。用可控发现结果覆盖候选选择、手填 ID、名称跟随/自定义、同步不覆盖配置及失败回退；另做真实模型发现与 Provider 联通验证。通过可重复事件样例校验 UI 状态。
