# 09 — 多会话协作与写操作协调

最终收口补充：实现会话状态、停止、真实审批载荷与批准／拒绝；失败保留草稿与已完成步骤，未知外部结果先核对。导航为有界稳定标签、搜索归档列表及右键菜单，最后会话归档不新建。17 在此基础上扩展持久事件与跨项目关注。见 [收口规则](../../../docs/product-design-closure.md)。

**What to build:** 一个任务可拥有实现、排查和审查等多个会话；其中一个执行有副作用的工作时，其他会话可以安全阅读分析。

**Blocked by:** 04 — 图形化环境配置与单服务运行；06 — Agent 控制任务浏览器。

**Status:** ready-for-agent

**Parent:** [首版规格](../spec.md)。

- [ ] 同任务会话分别持久化对话，共享明确的代码和运行环境；切换会话不重建任务。
- [ ] 同一任务同时只有一个会话持有写操作权，界面显示持有者、排队/只读状态和中止入口。
- [ ] 文件修改、配置、进程控制及页面变更均遵循同一协调规则；只读会话不获得可绕过限制的任意执行工具。
- [ ] 写操作权持续覆盖工具及派生执行，不因某次对话流结束而提前释放。
- [ ] 取消、异常及恢复后，核验所属执行资源再释放或恢复写操作权，避免遗留进程与新会话并发修改。
- [ ] 同项目和跨项目的不同任务／会话可在非重叠资源上同时执行写操作，不以项目级或全局单会话锁串行化所有工作；共享普通目录的冲突写入遵循待细化的真实路径协调。
- [ ] 项目／任务切换只改变当前视图；隐藏项目中的 Agent 和本地服务继续执行，结果和用量归属原任务／会话，返回时可继续查看。

- [ ] 按规格「会话权限选择」实现输入框「+」后的常驻入口及就地浮层，支持只读／默认权限／自动执行、说明、当前标记与键盘操作。
- [ ] 以稳定任务／会话身份持久保存权限；新会话默认权限，名称不决定实际权限。切换保留文字／附件草稿、模型与历史，其他会话不受影响。
- [ ] 工具层统一校验：只读禁止写操作、命令与浏览器操作；默认权限的 Agent 命令／浏览器操作先询问，拒绝或取消后不执行；自动执行不逐次询问，但仍受任务范围、共享模板确认、显式交付和任务写锁约束。
- [ ] 记录请求实际采用的权限，选择用于后续请求；在途请求及已启动的 Subagent 保留启动时权限。明确审批等待、拒绝、取消与恢复状态，并验证派生执行不能越权。

- [ ] 接入 03 的混合目录来源，按解析后的真实路径校验权限，覆盖链接改指和嵌套链接；在实现前细化共享普通目录及重叠路径的跨任务／项目写协调，验证取消与派生执行，不能将任务级锁当作共享文件隔离。

**验证方式：** 两个同任务会话与同项目另一任务、另一项目的任务同时运行，检查同任务写操作串行及跨任务并行。执行中往返切换项目，验证隐藏任务的 Agent／服务仍推进、结果归属正确，再检查取消与恢复后的行为。
