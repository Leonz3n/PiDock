# 01 — 可见浏览器控制原型

**What to build:** 用户能看见并接管自动化正在操作的内嵌页面；在同一桌面原型中验证两个任务的页面与登录状态隔离，为桌面技术选型提供运行证据。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

**Parent:** [首版规格](../spec.md)。

- [ ] 原型只回答内嵌页面控制与隔离问题，产出可重复的演示步骤和技术结论；受控页面测试不替代真实业务验收。
- [ ] 自动化操作用户看见的同一页面，按角色/标签填写控件，等待异步变化；不得用另一个隐藏浏览器的成功代替。
- [ ] 能按需获得截图、相关控制台错误与失败请求；输出有界，避免每步转储全部内容。
- [ ] 两个任务使用不同持久浏览器会话；同站点分别登录或保存测试标记，重开后互不覆盖。
- [ ] 人工接管暂停后续自动化操作，恢复时重新读取页面状态；页面关闭、弹窗和开发者工具开关有明确失效/恢复行为。
- [ ] 用运行证据决定内嵌页面与自动化接口的组合；记录 iframe、下载等能力是否通过及未解决问题。
- [ ] macOS/Windows 分别记录实测结果与待测项；没有可用 Windows 环境时保留明确的平台验证关卡，不能声称跨平台通过。

**验证方式：** 端到端驱动两个可见页面，断言实际 DOM 变化、独立存储和错误证据；保留结果与适配方案。技术失败先修订方案，不直接进入产品集成。
