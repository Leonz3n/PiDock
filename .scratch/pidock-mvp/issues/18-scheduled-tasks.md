# 18 — 定时任务与可续聊历史

**Status:** ready-for-agent

**What to build:** 普通／定时任务统一创建，Host 按规则在固定工作区内启动独立会话，内置五个可编辑提示词模板。

**Blocked by:** 03 — 工作区；11 — Provider；17 — Host 事件与审批。

父规格：[首版规格](../spec.md)；[设计收口](../../../docs/product-design-closure.md)。覆盖用户故事 65–69。

- [ ] 保存 Provider 身份／模型、权限、提示词、规则、IANA 时区及版本；每日／每周／一次性／五段 Cron 真实校验并预览下一次触发。
- [ ] 五个模板应用后可修改，保留项目、模型、权限和时区；统计模板获取远程新记录但不自动合并工作区。
- [ ] 每次执行创建同任务内独立会话，保留记录，可定位历史并继续对话。
- [ ] 待确认至 24 小时或下次计划时刻较早者过期；先结束旧确认再判断新周期，编辑规则不延长旧确认。
- [ ] 运行重叠跳过、离线不补跑；时钟回拨、夏令时、重启不重复触发。到期与人工批准竞态只产生一个结果。
- [ ] 归档停止并暂停，恢复不自动启用；归档任务无法立即运行；配置失效不静默换模型或项目。
- [ ] 失败获取不使用陈旧数据声称成功；结果处理在提示词中，实际发送仍按工具和确认规则。

交付演示：真实受控时钟触发、确认超时后下一周期、历史续聊、归档恢复及无重复执行证据。
