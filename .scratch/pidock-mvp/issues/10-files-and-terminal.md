# 10 — 文件浏览、差异与内置终端

**What to build:** 用户在任务中浏览各仓库文件和变化，打开对应工作目录的终端，并能与 Agent 协调人工接管。

**Blocked by:** 09 — 多会话协作与写操作协调。

**Status:** ready-for-agent

**Parent:** [首版规格](../spec.md)。

- [ ] 工具区默认关闭，通过任务顶部入口或对话内关联操作按需打开运行、浏览器、文件、终端及日志面板，只显示已打开的标签；支持逐个关闭及收起，最后一个关闭后释放对话空间。未打开工具不预先创建其运行资源，关闭面板不隐式停止任务服务、结束终端进程或删除浏览器持久状态。
- [ ] 文件树、预览和 Git 差异明确显示所属任务与仓库，多仓库变化不会混为一个 Git 仓库。
- [ ] 内置 PTY 使用选定任务仓库的 cwd 和有效环境，支持输入、调整窗口、停止及有限历史；macOS/Windows 分别验证。
- [ ] 人工终端接管遵循已有写操作协调；任意命令不能被 UI 标为只读或仍受完整 OS 沙箱保护。
- [ ] 终端及其子进程有任务归属，停止操作不误杀别的任务；退出后显示实际状态。
- [ ] 用户可从任务打开外部编辑器，继续使用已有断点调试方式；不自动复制整套敏感编辑器配置。
- [ ] 提供明确的 Git 交付操作或关联终端入口，执行前显示目标仓库与分支，不自动提交、推送或合并。

- [ ] 文件／命令／浏览器相关入口使用 09 定义的会话权限：只读不提供可绕过限制的命令执行；默认权限对 Agent 命令先询问；自动执行仍不绕过任务归属、共享模板确认或写操作协调。人工显式操作与 Agent 自主调用分别标识。

- [ ] 文件与终端可选择所选 worktree 或普通目录链接；显示统一 pi 工作目录、链接位置及原始目标。普通目录标明修改影响原文件，不提供 Git 差异／交付；引用保留来源身份及链接内路径。

**验证方式：** 在两个任务中打开终端检查 cwd、环境和进程归属，配合会话接管验证变化可见性及副作用协调。检查工具初始关闭、顶部/对话入口、逐标签关闭和收起；确认面板关闭后所属服务、终端及浏览器状态按既定生命周期保留。
