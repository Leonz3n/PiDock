# 17 — Host 执行状态与关注入口

**Status:** ready-for-agent

**What to build:** 统一桌面 Host 的执行、审批、恢复事件与跨项目关注列表，供桌面、定时和远程入口复用。

**Blocked by:** 09 — 会话协调；12 — 调用与用量；14 — 生命周期。

父规格：[首版规格](../spec.md)；[设计收口](../../../docs/product-design-closure.md)。

- [ ] 持久记录执行、步骤、调用尝试、确认请求及其版本，按项目／任务／会话定位。
- [ ] 实现执行中、待确认、失败、完成、停止、拒绝、过期的转换，服务状态与会话状态分开。
- [ ] 确认显示实际载荷、目标与影响；批准只消费一次且执行前复核权限／期限／版本。
- [ ] 失败保留草稿和已完成步骤；未知外部结果先核对，不自动重放发送；每次尝试单独记录用量。
- [ ] 跨项目关注列表展示待处理和完成未读；点击定位原会话，读取完成清除未读。
- [ ] 主机重启、客户端重连、迟到批准不重复执行，停止覆盖派生执行但不回滚已完成操作。

交付演示：两个项目并行，一边等待审批一边完成；跨入口处理同一确认不会执行两次。
