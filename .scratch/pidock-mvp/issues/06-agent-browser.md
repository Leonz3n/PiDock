# 06 — Agent 控制任务浏览器

**What to build:** pi 在任务中打开内置页面，通过语义操作完成交互，用户可看见并接管，任务重开后保留自己的登录状态。

**Blocked by:** 02 — 单仓库任务与 pi 会话；已包含 01 的浏览器路线验证。

**Status:** ready-for-agent

**Parent:** [首版规格](../spec.md)。

- [ ] 将已验证的页面控制能力接到 pi 工具，所有标签页句柄绑定任务；过期句柄和其他任务句柄均不能误用。
- [ ] Agent 可获取精简页面状态、导航、定位点击、填写、键盘操作并等待状态变化；支持按需截图。
- [ ] 按需返回当前操作相关的控制台及网络失败证据，限制内容体积。
- [ ] 分区归属于任务，具体页面句柄归属于视图并绑定任务；同任务标签页与登录弹窗复用分区并共享 Cookie／同源 localStorage，不同任务持久状态独立。验证弹窗登录回到原页、关闭再开标签和应用重启；首次用户登录后 Agent 继续使用同一页面。
- [ ] 用户接管时暂停后续操作，恢复时刷新页面状态；关闭、重载、弹窗和重连有明确可见状态。
- [ ] 浏览器操作接入 02 的权限门禁并遵循任务执行协调：只读禁止 Agent 浏览器操作，默认权限先询问，拒绝／取消后不操作页面，自动执行仍校验任务归属；验证所有浏览器工具均不能绕过门禁。外部网页不获得桌面本机能力。
- [ ] 检查已知前端地址覆盖项时保留登录数据，实际网络目标与任务运行配置一致。

**验证方式：** 通过真实 pi 工具完成同一可见页面交互，并重复两个任务的存储隔离和人工接管测试；尚未接入业务时只报告工具能力通过。
