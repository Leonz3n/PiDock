# 12 — Token 用量明细与汇总

**What to build:** 用户在对话中查看模型调用用量，在统计页按时间、项目、任务、会话、Provider 和模型查看累计消耗，重启与恢复历史后结果保持一致。

**Blocked by:** 11 — 多 Provider 与会话上下文状态。

**Draft:** 待拆分审阅，未发布。

**Parent:** [首版规格](../spec.md)。

**Context:** [pi usage 字段与限制](../../../docs/pi-provider-usage.md)。

- [ ] 从已有稳定调用记录构建持久用量明细，记录原始归属、Provider 配置版本、请求模型/可用实际响应模型、调用时间、类型、结束状态和 usage 完整性。
- [ ] 展示单次模型调用和会话累计的输入、输出、缓存读取、缓存写入；reasoning 是 output 子集时仅展开，不重复相加。归一化不得将 Provider 的缓存或总量再次累加。
- [ ] 支持时间范围及项目/任务/会话/Provider/模型分组，统计定义在界面可查；日期边界和时区口径一致。
- [ ] 流式增量、最终消息和事件重放更新同一调用，重启或重复读取 pi 会话累计值不新增消耗。
- [ ] 重试为不同尝试，已报告用量分别计入；失败、取消和缺失报告明确区分已知值与未知，不把 SDK 零初始化当供应商实报。
- [ ] 压缩、分支摘要和模型型工具调用的可观测用量纳入对应类型；上下文占用下降不冲减累计消耗。
- [ ] 恢复、分支/克隆或重新导入会话时保留来源身份，原历史只计一次，继承展示不改变原调用的任务/会话归属。
- [ ] Provider 改名或切换不重写历史统计；归档保留用量，清理会话与清理用量的范围可明确表达。
- [ ] 未观测到的外部调用或上游未返回用量不伪造；页面标识统计为本应用记录，不宣称等同账户账单或配额。

**验证方式：** 使用可预期的跨 Provider usage 数据，覆盖缓存/reasoning、工具、压缩、重复事件、重试、取消、克隆和重启，逐层比较明细与汇总；少量真实请求验证接入与字段来源。
