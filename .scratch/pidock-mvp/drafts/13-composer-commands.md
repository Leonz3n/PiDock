# 13 — 对话引用、技能与符号命令

**What to build:** 用户在对话中通过 `@` 引用当前任务的文件、目录和代码片段，通过 `$` 调用技能，通过 `/` 操作会话；候选、来源预览、实际执行和草稿恢复保持一致。

**Blocked by:** 03 — 多仓库任务；10 — 文件浏览、差异与内置终端；12 — Token 用量明细与汇总。

**Draft:** 待拆分审阅，未发布。

**Parent:** [首版规格](../spec.md)，覆盖用户故事 51–58；接入边界见 [pi 输入能力核对](../../../docs/pi-composer-capabilities.md)。

- [ ] 输入框底部左侧仅显示「+」附件入口，调用真实系统文件选择器，支持多选、取消、显示附件名和移除；模型选择位于底部右侧、发送按钮之前。输入符号仍补全，但不常驻显示 @/$/ 按钮。
- [ ] 用户选择的本机附件与任务代码引用区分来源，选择外部文件不授权访问整个目录；发送前检查支持类型和大小，明确实际提供范围，失败不伪装已送达。
- [ ] `@` 模糊搜索当前任务各仓库文件与目录，候选显示仓库及相对路径；文件视图选中的代码可插入对话，引用可预览、删除并显示范围。
- [ ] 发送时读取所选任务 worktree 或已关联普通目录，记录实际来源、内容范围及版本；同路径文件不串仓库或任务，文件移动、来源失效或越界时要求重新选择，不回退到主检出目录。
- [ ] 默认文件搜索尊重忽略规则；目录、大文件、二进制及长片段有明确范围和限制，界面说明实际送入上下文的内容，预估大小不记为实报 Token。
- [ ] `$` 按技能名或描述搜索已启用的全局、项目及任务仓库来源，允许显式添加来源；重名技能选择具体来源，保留技能资源相对路径和参数，并兼容 `/skill:name`。
- [ ] 一条消息可以组合自然语言、多个引用与技能；结构化输入与发送后的来源记录分开于渲染文字保存，SDK 展开不重复，历史查看不重新执行技能。
- [ ] `/` 在消息开头显示应用操作、提示模板和可接入扩展的分类菜单，显示来源、参数及可用状态；同名入口可消歧，未知命令提示纠正。
- [ ] 首版支持 `/new`、`/model`、`/compact`、`/skills`、`/session`、`/usage`、`/help`。实际调用相应应用能力；新会话仍归当前任务并保留旧历史，模型切换保留上下文，用量菜单展示已有统计，不依赖模型猜测命令含义。
- [ ] `/model` 打开与输入框相同的模型选择浮层，沿用 11 号草案的超限禁止切换校验；不能通过命令绕过容量限制或隐式压缩历史以完成切换。
- [ ] 方向键选择，Tab/Enter 确认候选且不同时发送，Esc 关闭候选；普通输入 Enter 发送、Shift+Enter 换行，中文输入法组合输入确认不提交消息或执行命令。
- [ ] 邮箱、URL、Unix/Windows 路径、行内代码、代码块、普通 `$HOME` 和转义符号保持原文；未选中或未明确解析的标记不触发操作，也不进行 shell 展开。
- [ ] 忙碌时按命令类型显示等待或不可用；切换模型、新会话和压缩遵循空闲边界，扩展命令不能借 prompt 即时分派绕过协调。普通消息明确选择 steer/follow-up，快捷入口不扩大只读会话或任务权限。
- [ ] 各会话草稿保存文字、引用和技能来源；切换任务或重开时校验来源，失效项可修正，恢复不自动发送消息或重放命令。

- [ ] `@` 同时搜索任务选中的 worktree 和普通目录来源；链接内路径、显示名与真实目标分开保存，发送前检查实际来源权限、失效链接及同名文件，普通目录不伪造 Git 版本。

**验证方式：** 在两个包含同名文件的多仓库任务中，通过真实输入框完成混合引用、技能及应用命令操作，核对 Agent 实际收到的来源与内容；覆盖重名技能、忙碌扩展、失效来源、草稿恢复、中文输入法和两平台路径，不以仅测字符串解析代替验收。
