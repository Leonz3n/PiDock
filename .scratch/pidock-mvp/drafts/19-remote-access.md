# 19 — 远程访问、配对与移动端

**What to build:** 手机通过 Tailscale 私有入口或自建 Gateway 访问同一 Host；Funnel 为实验入口。

**Blocked by:** 17 — Host 执行事件与授权。与 18 可并行，最终验收覆盖定时任务远程查看。

父规格：[首版规格](../spec.md)。状态：拆分草案，未发布。覆盖用户故事 61–64。

- [ ] 二维码短时单次凭据、登录与桌面确认、逐设备权限／撤销／轮换；旧码失效。
- [ ] 手机可查看任务会话并对话，待确认操作展示同一真实内容；不扩大桌面会话权限。
- [ ] 主机主动连接 Gateway；TLS、认证、请求路由、限流、审计和部署说明完整；不代理任意 TCP 或暴露 Pi RPC。
- [ ] 文件／终端默认关闭，管理操作按设备权限确认；断线显示离线，不盲目重放消息或管理请求。
- [ ] 移动端会话选择、归档历史、审批、失败恢复均可操作；网络可达不等于授权成功。

交付演示：真实手机配对、对话与撤销，断线后重连不重复发送，三种网络入口分别记录支持范围。
