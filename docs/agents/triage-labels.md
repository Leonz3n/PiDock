# GitHub 工单状态

以下五种 triage 角色使用同名 GitHub label：

| Label | 含义 |
| --- | --- |
| needs-triage | 待评估 |
| needs-info | 待补充信息 |
| ready-for-agent | 规格完整，可由 Agent 实现；仍须遵循执行控制与依赖 |
| ready-for-human | 需要人工实现 |
| wontfix | 不处理 |

完成由 GitHub 的 open/closed 状态及验收/执行记录表达，不新增 done 或 in-progress triage label。暂停写入父规格与 issue 的执行控制；当前首版所有未完成工单保持暂停。
