## 页面细节

### S01 · 任务对话

导航使用「项目总览 / 定时任务 / 项目树 / 已归档 / 设置」。主要画布为任务名、简短事实条、会话标签、消息、底部输入框。示例项目 PiDock，任务「优化任务创建流程」，会话「实现方案 / 代码审查」。支持新会话空态、普通对话、流式执行与停止、错误保留输入、待确认与拒绝/过期。执行状态必须归属具体会话和任务。

参考图的初稿消息可用于排版，不可将其“已检查文件”或测试退出码当作真实事实。为生产设计新增加载、状态未知和流式文本；不复制原型页的调试按钮。Composer 左下为附件/引用与权限，右下为 Provider/模型和发送/停止；上下文与累计用量分开。

### S02 · 任务信息

默认关闭，显示每个来源的名称、类型、方式、路径、分支/基线、准备状态。示例：pidock 为独立 worktree，design-notes 为普通目录共享原文件。标题不要只写“任务已隔离”。主画布不增加文件树、Diff 或浏览器。

### S03 · 项目

任务列表提供普通/定时筛选。来源区域区分 Git 与普通目录。来源移除是解除引用，已绑定任务不偷偷改用其他路径。空项目提供一个明确的「添加来源 / 新建任务」下一步。未归属任务单独标注；用户显式选定项目后才能认领。

### S04–S05 · 创建与准备

覆盖 Git 已有目录、独立 worktree、普通目录三种来源事实。每仓库独立选择模式，支持纯普通目录任务。worktree 显示仓库、基线分支、目标任务分支和独立路径；实际 fetch 成功后固定提交，失败不冒充成功。名称和路径要分开，重命名不会重新绑定工作目录。

准备页用逐来源步骤/结果，不伪造百分比。部分失败列出失败原因、保留的已准备内容、恢复/修复/退出入口。未完成来源准备时不能启动相关执行。无图状态：原目录移动、路径无权限、身份不匹配、未提交改动保护。

### S06 · 会话生命周期

最多四个可见标签，溢出时当前会话仍可见。全部会话支持搜索、未归档/已归档分组。每项带消息/最近活动与执行状态。重命名保持身份；归档保留历史；恢复不自动执行。删除前列出历史与草稿范围，并明确任务、worktree、普通目录保留。关联定时记录呈现「会话已删除」，不改指向其他会话。

### S07–S08 · 定时任务

规则属于任务，运行历史属于每次独立会话。模型/凭据/目录失效是失败，不默认换一个模型。等待审批算未结束执行，重叠触发应跳过并记录理由。归档任务禁用「立即运行」；恢复任务不自动启用。规则允许一次性与周期、明确时区。真实下次运行时间未知时不填造假的“明天”。退出/休眠期间不执行、不补跑的说明靠近启用入口。

### S09–S11 · 能力设置

设置分类为模型服务 / MCP 连接 / Skills / 通用。示例卡片数据只能帮助版式，不代表连接已通过。

Provider 编辑要包括名称、endpoint、凭据状态/替换入口、模型列表。凭据用虚拟占位文字，禁止采集或展示真实 API Key。两个 profile 可提供同名模型，会话必须明确区分。MCP 需要连接中、已连接、已停用、失败和具体原因，不以一个开关代替全部连接状态。Skills 要包含本地来源、加载/失效状态和加入当前草稿的入口。配置生效时间明确为安全会话边界。

### S12 · 任务收尾

归档和清理是两个动作；会话删除又是另一个范围。清理清单展示普通目录/已有工作目录原文件保留、独立 worktree 未交付改动检查与保留位置、会话与草稿处理、定时记录状态。资源清理失败保留登记与恢复入口，不显示整体成功。跨平台文件路径采用清晰截断/展开方式。

### S13 · 窄窗口

输出独立 720×560 桌面画板，不是手机 UI。隐藏导航后仍能打开项目和设置；输入框/发送/停止保持可达；详情浮层有明显关闭入口；对话框内部滚动，标题与底部操作固定。长路径和中文标题不撑出横向滚动。

## 交付画板要求

- 每屏命名为 `Sxx-页面名-状态-尺寸`，例如 `S01-任务对话-等待确认-1440x900`。
- 先完成 S01 / S02 / S04 / S13，确认阅读密度和主流程，再扩展其他页面。
- 至少额外交付：新会话空态、执行中可停止、操作待确认、失败保留草稿、来源准备失败、MCP 连接失败、清理部分失败。
- 共用品牌、导航、文字、间距、按钮与状态样式；提供主要组件的默认/悬停/焦点/禁用/错误状态。
- 返回一份简短变更说明：相较初稿改善了什么；哪一项产品规则仍需决策。设计图不是功能验收证据。
