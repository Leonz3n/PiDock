# PiDock UI 设计

**[PiDock.pen](PiDock.pen) 是当前唯一的 UI 设计基准。** 后续界面的布局、视觉、控件位置和关键交互以这份 Pencil 文件为准。

旧 HTML 原型、Quiet Ledger / Stitch Apple 候选、SVG / Figma 导入稿、参考图、旧 tokens、生成脚本、压缩交付包及候选比较文档已移除。需要追溯时查看 Git 历史，不从历史方案中拼接新的实现要求。

## 文件入口

| 文件 | 用途 |
| --- | --- |
| [PiDock.pen](PiDock.pen) | 在 Pencil 中打开和继续编辑的唯一设计稿，包含 17 个画板 |
| [APPEARANCE.md](APPEARANCE.md) | 同一份 Pencil 设计的日间 / 夜间主题说明与验证范围 |
| [appearance.tokens.json](appearance.tokens.json) | 同一套主题的语义色和对比度数据，供实现取值 |

`.pen` 文件关联 Pencil 文档；请使用 Pencil 打开查看画板，不能仅根据本地文件的 `children` 字段判断设计是否存在。两个外观文件是该设计的配套资料，不构成独立方案。修改主题时同步更新三者，避免颜色数据分叉。

## 当前设计约定

- **工作空间与任务分开。** 可复用工作空间登记仓库、普通目录、环境变量和分支约定；任务选择部分来源，为选中的 Git 仓库自动准备独立 worktree。普通目录仍访问原始文件。早期文档和部分画板沿用「项目」名称时，按这里的可复用来源管理层理解，不把它与任务工作区混为一谈。
- 工作空间、任务、会话分别有自己的入口；术语统一见 [GLOSSARY](../../GLOSSARY.md)。Git 默认自动准备 worktree，同时保留显式已有 Git 目录模式；对话中保留任务路径、分支和提交等事实信息。
- 定时任务复用自己的任务工作区，每次执行创建独立会话；结果可以继续对话。
- 左下角提供独立的「能力管理」与「设置」两个入口；紧凑窗口分别使用 blocks 与 settings-2 图标。两者均替换工作区导航，使用专用导航和整窗内容区；返回时保留原任务、会话和草稿。
- 能力管理默认打开 Providers，首版导航仅包含 Providers、MCP、Skills。Extensions、Computer Use、Browser 属于后续规划，首版不提供入口、占位页或管理验收。
- 设置默认打开外观，导航包含外观、快捷键、语言和通用偏好；模型服务、工具与技能配置归属能力管理。
- 供应商添加 / 编辑替换列表所在内容区。配置包括协议、API Key、Base URL、预设和模型发现；未获取模型时手填 ID，获取成功后增加下拉选择，同时保留手动输入。
- Pi Agent 的模型、MCP、Skills、快捷键与相关通用设置以其原生默认配置为管理对象；PiDock 的外观、界面语言等应用偏好由 PiDock 管理。目标改为 Pi 1.5.0，实际依赖仍为 1.4.0，升级归 #134；配置格式、参数转换和接入边界见 [1.5 升级设计](../architecture/pi-1.5-upgrade-design.md)。画板中的路径、传输协议、模型、计数和连接状态是示例，不作为已验证 SDK 契约；Extensions 的用户管理整体延后，不因 MCP 使用官方扩展就增加首版 Extensions 管理页面。
- 工作空间变量继承与任务覆盖属于基本配置，不恢复服务环境模板或编排。分支约定提供推送目标，实际提交 / 推送 / PR 由明确操作触发；画板“自动创建远端分支”描述推送时的效果，不授权任务完成后无确认推送。
- 推理强度紧邻模型选择，使用紧凑的分段胶囊；档位来自实际模型能力，支持关闭时才显示关闭，并反馈 SDK 实际生效值。模型显示名与 ID 分开，不被上游新默认模型覆盖；对话输入区不常驻展开推理菜单。
- MCP 连接使用 stdio / Streamable HTTP，不支持 legacy SSE；保留原生 OAuth 注册模式与明确登录／取消／失败状态，授权页使用系统浏览器。首版显式接入 direct 受管工具子集，不因原生默认暴露模式自动增加 codemode。Skills 的验证警告与重名冲突分别显示，同一 Windows 来源的盘符大小写变体不重复加载。
- 工具参数流式片段只作预览，审批展示实际执行参数；消息费用若展示，区分供应商实报与估算，未知不显示为零。CLI 自更新、扩展更新通知及 TUI 专用设置不进入首版偏好。
- 提供日间、夜间、跟随系统三种外观偏好。日间使用暖灰 / 纸白，夜间使用炭灰 / 浅灰，强调色为雾蓝；不使用绿色。外观偏好属于 PiDock。
- 桌面画板为 1440×900，最小窗口为 720×560；对话列目标宽度 768px，统一顶部栏 52px，输入区采用浮动 Composer。

## 实现与验收

功能范围与执行安排仍以 [GitHub 首版父规格 #1](https://github.com/Leonz3n/PiDock/issues/1) 和 [首版收口 #135](https://github.com/Leonz3n/PiDock/issues/135) 为入口；文档与工单按当前设计整理，产品实现仍保持暂停。布局与外观按本文件指向的 Pencil 设计验收，历史规格快照中的旧 UI 要求已失效。

`packages/renderer` 中的现有界面、样式、测试及注释记录的是已有实现，不代表已对齐本设计；`docs/evidence/` 的截图与日志用于追溯当时的运行验证，也不作为现行 UI 设计依据。设计稿检查通过不代表真实配置读写、Git 操作、模型调用或应用主题切换已经实现。
